# 전시 꾸밈용 비정형 오브제

만드는 길이 둘이다.

## 1. 브라우저 스튜디오 (직접 조절할 때)

```
python3 -m http.server 5605 --directory .
```
열고 `http://localhost:5605/studio.html` 로 간다.

슬라이더로 굵기, 굵기 변화, 끝 가늘기, 구부러짐, 납작한 정도, 요소 수를 돌리면
바로 형태가 바뀐다. 마음에 들면 STL 내보내기를 누른다. 크기 mm 와 내보내기
해상도는 따로 두어서, 미리보기는 가볍게 돌리고 내보낼 때만 촘촘하게 뽑는다.
새로 뽑기를 누르면 씨앗이 바뀌어 완전히 다른 모양이 나온다.
유리처럼 보기는 최종 느낌을 가늠하는 용도다. 실제 출력물과는 다르다.

내부 메모. three.js MarchingCubes 의 장은 `val = strength/d^2 - subtract` 이고
표면은 합이 `isolation`(기본 80)일 때다. 그래서 반지름 R 을 내려면
`strength = R^2 * (isolation + subtract)` 이어야 한다. 소스 538행의
`sqrt(strength/subtract)` 는 계산 범위를 줄이려는 영향 반경이지 표면 반지름이
아니다. 이걸 표면으로 쓰면 공이 36% 크기로 나와 덩어리가 끊어진다.

## 2. Blender 일괄 생성 (여러 개를 한 번에)

레퍼런스의 형태 언어를 만들어 STL 로 내보낸다.
스튜디오와는 구현이 달라서 같은 씨앗이라도 같은 모양이 나오지는 않는다.

```
/Applications/Blender.app/Contents/MacOS/Blender -b --python make_blobs.py -- \
    --out stl --count 6 --size 80 --seed 7
```

`--seed` 를 바꾸면 완전히 다른 모양이 나온다. `--count` 를 늘리면 더 많이 만든다.
미리보기는 이렇게 만든다.

```
/Applications/Blender.app/Contents/MacOS/Blender -b --python preview.py -- --src stl --out preview.png
```

## 형태 셋

| 종류 | 생김새 | 출력 난이도 |
|---|---|---|
| `arc` | 휘어진 관, 끝이 가늘어짐 | 서포트 필요 |
| `loop` | 구멍이 뚫린 고리 | 눕히면 대체로 무난 |
| `ribbon` | 납작하게 퍼진 판 | **서포트 없이 가장 깨끗함** |

## 속을 비우는 방법

**모델을 껍데기로 만들지 말고 슬라이서에서 비우는 쪽이 낫다.**

BambuStudio 에서 벽 2줄, 인필 0% 로 두면 자동으로 속이 빈다. 모델 자체를
Solidify 로 껍데기로 만들면 안쪽 면까지 벽으로 찍혀서 필라멘트를 오히려 더 쓰고,
내부 면 때문에 빛이 산란해 더 탁해진다.

꼭 모델에서 처리하고 싶으면 `--shell 1.2` 처럼 두께를 주면 된다. 기본은 꺼져 있다.

`ribbon` 만큼은 **스파이럴 베이스 모드**를 쓸 수 있다. 벽 한 줄이라 필라멘트가
가장 적게 들고 투명도도 제일 낫다. 다만 구멍이 있는 `loop` 는 한 레이어에 윤곽이
둘이라 베이스 모드가 안 된다.

## 투명 필라멘트에 대해

레퍼런스 이미지는 렌더라서 유리처럼 맑다. **투명 PLA 나 PETG 로 뽑으면 그만큼
맑지 않고 서리 낀 반투명이 된다.** 더 맑게 하려면

1. 노즐 온도를 올리고 속도를 낮춰 레이어가 잘 붙게 한다
2. 인필 100% 가 가장 맑지만 필라멘트를 가장 많이 쓴다. 목적과 반대다
3. 사포질 후 투명 코팅이나 에폭시를 입히면 실제로 광이 난다

서리 낀 반투명도 전시 조명 아래에서는 충분히 좋다. 다만 레퍼런스 그대로를
기대하면 실망할 수 있어서 적어둔다.

## 서포트

`arc` 와 `loop` 를 세워서 찍으면 오버행에 서포트가 붙고, 떼어낸 자국이
투명한 표면에 그대로 남는다. 가능하면 눕히고, 서포트가 꼭 필요하면 보이지 않을
면에 닿게 방향을 잡는다. `ribbon` 은 바닥이 넓고 높이가 10mm 안팎이라
서포트 없이 깨끗하게 나온다.
