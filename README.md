# 가상 샹들리에

Playground 파생작. 천 위에 손가락으로 그리면 크리스탈 하나가 태어나 천장의
가상 샹들리에에 매달린다. 관객은 자기 폰으로 QR 을 스캔해서 본다.

```
천 + ToF 9개 -> ESP32 -> (USB) -> 허브 -> Firebase -> 관객 폰 웹 AR
```

## 관객이 여는 주소

**https://jwyang29.github.io/raonsum-chandelier/**

| 주소 | 무엇 |
|---|---|
| `/` | 관객이 보는 AR. QR 은 이 주소로 만든다 |
| `/venue.html` | 전시장에 놓인 모습 미리보기. AR 없이 비례를 본다 |
| `/camtest.html` | 현장에서 카메라와 마커 검출만 확인 |

`main` 에 올리면 `.github/workflows/pages.yml` 이 `web/` 만 자동으로 배포한다.
저장소 루트가 아니라 `web/` 이라서 주소에 `/web/` 이 안 붙는다.

## 로컬에서 보기

```
python3 -m http.server 5604 --directory web
```

열 때 쿼리를 붙인다.

- `?mock=1` Firebase 없이 가짜 크리스탈을 4초마다 만든다
- `?debug=1` 보이는 마커 수, 크리스탈 수, 품질 단계, fps, 월드 원점을 표시한다

카메라는 HTTPS 또는 localhost 에서만 열린다. 폰으로 볼 때는 GitHub Pages 에 올려야 한다.

## Firebase 설정

**끝났다 (2026-10-29).** 다시 만들 일이 있을 때만 보면 된다.

1. 콘솔에서 **Realtime Database** 를 만든다. Firestore 가 아니다.
   위치는 `asia-southeast1` (싱가포르). 셋 중 한국에서 제일 가깝고 나중에 못 바꾼다.
2. 규칙 탭에 [`hub/firebase_rules.json`](hub/firebase_rules.json) 을 통째로 붙여넣는다.
   crystals 만 읽기가 열리고 그 바깥은 막힌다. 쓰기는 권한 없이는 안 된다.
3. 주소를 `web/config.js` 의 `databaseURL` 에 넣는다. 허브도 이 값을 읽으므로
   주소를 적는 곳은 여기 하나뿐이다.
   SDK 를 안 쓰고 REST 스트리밍을 직접 읽으므로 `apiKey` 도 `projectId` 도 필요 없다.
4. 허브 쓰기 권한은 `hub/secrets.env` 에 넣는다 (`.gitignore` 에 있다).

```
cp hub/secrets.env.example hub/secrets.env
```

5. 확인한다. ESP32 없이 읽기, 쓰기, 지우기를 해 보고 시험용 한 개는 지운다.

```
python3 hub/hub_v1.py --check
```

🔴 데이터베이스 비밀번호는 모든 규칙을 무시하는 관리자 열쇠다. 콘솔에서 사라졌으면
Authentication 에 허브 계정을 만들어 `RAONSUM_FIREBASE_APIKEY` / `_EMAIL` /
`_PASSWORD` 를 쓰면 된다. 허브가 알아서 토큰을 받고 갱신한다.

## 데이터 계약

RTDB `crystals` 아래에 획 하나가 문서 하나로 쌓인다.

| 키 | 범위 | 뜻 |
|---|---|---|
| `press` | 0~1 | 누른 깊이. 크리스탈 두께 |
| `speed` | 0~1 | 빠르기. 투명도 |
| `elong` | 0~1 | 길쭉함. bbox 종횡비 |
| `wind` | 0~1 | 맴돈 정도. 면 분할 |
| `curl` | 마이너스1~1 | 부호 있는 비틀림 |
| `dir` | 라디안 | 시작점에서 끝점 방향 |
| `dur`, `n`, `t`, `feeling` | | 지속시간, 점 수, 시각, v24 의 느낌 이름 |

정규화 범위는 녹화 4개의 획 25개를 실측해서 정했다. press 22~46mm, speed 2~36cm/s.
천 장력이나 센서 높이를 바꾸면 `probe_ranges.py` 를 다시 돌려서 맞춘다.

## 원형 좌대

작품은 둥근 좌대 위에 올라가고 관객은 사방에서 본다. 앞뒤가 없다는 조건이
나머지 기하를 거의 다 정한다.

- **마커는 좌대 안에 들어가야 한다.** 네 장을 천의 네 변 쪽에 하나씩, 테두리
  가까이 놓는다. 전처럼 모서리 쪽(정사각형 배열)에 놓으면 대각선이 길어져
  간격 45cm 에 좌대가 82cm 는 돼야 하는데, 변 쪽으로 돌리면 59cm 면 된다.
  반지름은 `config.js` 의 `refreshPedestal` 이 좌대 지름에서 자동으로 잡는다.
- **높이는 전부 좌대 상단면 기준이다.** 현장에서 줄자로 재면 바닥 기준이
  나오므로 보정 패널이 좌대 높이를 빼고 넘긴다.
- **샹들리에 맨 아래는 머리 위여야 한다.** 관객이 좌대를 돌며 팔 길이 안으로
  들어오므로, 마지막 날 링이 눈높이에 걸리면 크리스탈이 얼굴을 통과한다.
  바닥 기준 `GEOMETRY.headroom` (기본 2.05m) 위로 띄운다.
- **하루 내려오는 높이 = (천장 - headroom) / 27.** 천장 3.4m 면 5.0cm,
  4.0m 면 7.2cm 다. 보정 패널 맨 위에 이 값이 뜬다.

## 마커

AR.js 바코드 마커, 3x3 matrix code 를 쓴다. 값은 0, 7, 44, 63, 26 다섯 개다.
0/7/44/63 은 좌대 위 네 방향, 26 은 천장 뼈대 아랫면이다.
0~4 를 안 쓰는 이유는 3x3 격자가 서로 한 칸밖에 안 달라서다 (회전 포함 최소
거리 1). 이 조합은 최소 거리가 3 이라 한 칸 잘못 읽혀도 다른 마커가 안 된다.

- 바닥 네 개는 한 변 10cm, 천장은 약 30cm
- 무광 인쇄, 평평하게, 네 개를 **같은 방향으로** 붙인다.
  둥근 좌대에는 맞출 모서리가 없으니 테이프로 기준선을 하나 긋고 그 선과
  나란히 붙이는 쪽이 쉽다. 방향이 어긋나면 `yaw` 를 넣어야 한다
- 인쇄물은 `markers/` 에 있다 (`make_pdf.py` 로 PDF 생성)

## 마커를 놓쳐도 되는 이유

샹들리에는 머리 위에 있고 마커는 발밑 좌대에 있다. 그래서 **샹들리에를 보는
자세에서는 마커가 화면에 없는 것이 정상이다.** 자이로 유지(`ANCHOR.gyroHold`)
가 예외 처리가 아니라 기본 동작이라는 뜻이고, 여기에 시간제한을 걸면 안 된다.

자이로는 기기가 돌아간 각도만 알고 관객이 걸어간 거리는 모른다. 그래서
좌대를 돌면 조금씩 어긋나고, `ANCHOR.hintSeconds` 뒤에 다시 비춰 달라고
안내한다. 다시 잡은 포즈가 `ANCHOR.snapMeters` 넘게 다르면 저역 필터로
따라가지 않고 한 번에 끊어서 맞춘다. 안 그러면 샹들리에가 공중을 가로질러
미끄러져 오는 게 보인다.

## 전시 전 체크리스트

- [ ] 좌대 **지름과 높이** 실측. 이 둘이 마커 반지름과 모든 높이를 정한다
- [ ] 현장에서 `?debug=1` 보정 패널에 바닥에서 천장까지, 좌대 높이, 좌대 지름을
      넣고 뜨는 값을 `config.js` 기본값에 적어 넣기
- [ ] 현장에서 `?debug=1` 로 월드 원점을 보면서 마커 위치와 `yaw` 맞추기
- [ ] 좌대를 한 바퀴 돌며 어느 방향에서도 마커가 하나는 잡히는지 확인
- [ ] A-Frame 과 AR.js 를 CDN 에서 저장소로 **내려받아 고정**하기.
      3주 무인 운영에서 외부 CDN 의 경로 변경이나 장애가 작품을 죽인다
- [ ] 아이폰과 안드로이드 실기 테스트. **카카오톡으로 QR 을 스캔한 경우**를 꼭 포함
- [ ] 포스터에 "휴대폰 카메라 앱으로 스캔" 문구
- [ ] 크리스탈이 많이 쌓인 상태에서 오래된 폰 성능 확인
- [ ] 누적 리셋 규칙 (시간 기준 또는 개수 기준) 결정하고 넣기

## 아직 비어 있는 것

1. **크리스탈 생김새.** `crystal.js` 는 임시 팔면체다. 디자인이 오면 이 파일만 바꾸면 된다.
   바깥과의 약속은 `makeCrystal(data)` 와 `setQuality(mesh, level)` 두 개뿐이다.
2. **기하 실측값.** 좌대 지름과 높이, 바닥에서 천장까지, 매단 링 반지름.
3. **천장에 매달 수 있는지.** 안 되면 기울기 센서 차선책으로 구현이 달라진다.
